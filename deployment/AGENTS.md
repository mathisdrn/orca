# AGENTS.md /deployment

This directory contains code related to deployment at `orca-datawarehouse.dev`. This includes:
- `cloudflare_worker.js`: Edge router handling domain routing, cold start loader, `/robots.txt`, aggressive bot blocking (e.g. Ahrefs, Semrush), and edge caching for static assets.
- `orchestration/`: Dagster UI in read-only mode hosted on GCP Cloud Run (`orca-dagster`). Access is protected by Google OIDC token generated by the Cloudflare Worker.
- `transformation/`: dbt docs hosted on GitHub Pages (`mathisdrn.github.io/orca/dbt-docs`).
- `dashboard/`: Embedded Streamlit dashboard (`orca-dashboard.streamlit.app`).

Cost & Safeguards note:
- Cloud Run Free Tier covers ~9 € of gross catalog compute. The GCP billing budget/spend cap is configured at 10 € to prevent premature suspension from gross cost forecasts while ensuring zero net costs.
